## 1. 需求概述

**目标**：团队用例库右侧**主列表区**：展示、筛选、搜索、分页与进入编辑/批量操作。

**页面**：`frontend/src/pages/CaseRepository.jsx`

---

## 2. 范围

### In Scope

- 团队范围内 `cases.status=active` 列表
- 来源 Tab：全部 / 录制 / 导入
- 文件夹筛选（与左树联动，见 REQ-H05）
- 关键词搜索（名称、标签、描述、创建人）
- 分页（默认每页 10，可选 20/50 P2）
- 行勾选 + 底栏批量操作入口
- 空状态：无用例 / 无搜索结果 / 当前文件夹为空

### Out of Scope

- 文件夹 CRUD（REQ-H05）
- 用例编辑内容（REQ-H02）
- 试跑执行（REQ-J02 / 编辑页试跑）

## 3. 数据与 API

### 3.1 列表 API

```
GET /api/cases?source=&folder_id=&q=
```

| 参数 | 说明 |
|------|------|
| `source` | `recorded` \| `imported`；省略=全部 |
| `folder_id` | 数字 ID；`uncategorized` = `folder_id IS NULL`；省略=全部（与左树「全部」一致） |
| `q` | 关键词（服务端或客户端，见 §4.2） |
| `portability` | P2：`portable` \| `bundle` |

响应：数组，元素见 `caseToApi()`，含 `id, name, source, folder_id, priority, tags, path, created_by, updated_at, metadata` 等。

**团队**：`team_id` 仅来自 `req.teamId`，客户端不可指定。

### 3.2 与目录树 API 配合

```
GET /api/cases/folders/tree  → 左树数据 + total + uncategorized 计数
```

列表 `total` 与树「全部」计数应一致（同一 `team_id`、同一 `status`）。

## 4. 前端行为规格

### 4.1 布局

遵循 [REQ-H00 §3](./REQ-H00-用例库页面总览.md#3-页面布局定稿线框)：左树 + 右表。

### 4.2 筛选组合逻辑

| 条件 | 行为 |
|------|------|
| 仅选文件夹 | `GET /cases?folder_id=X` + 客户端按 Tab 过滤 source |
| 仅选 Tab | `GET /cases` 或 `?source=` + 客户端不过滤 folder |
| 文件夹 + Tab | 先按 folder API 筛选，再 Tab 过滤 |
| **有搜索关键词** | **忽略文件夹**，拉全量（或 `q` 参数）后客户端过滤，避免「搜不到其他文件夹里的用例」 |

切换团队：重置文件夹为「全部」、清空搜索、刷新树与列表。

### 4.3 表格列

见 [REQ-H00 §4](./REQ-H00-用例库页面总览.md#4-表格列规范-req-h01)。

**Phase B 必须完成**：

- 移除「路径」默认列
- 操作列改为：`编辑` + `更多 ▾`（复制、删除）
- 「备注」移入更多/抽屉

### 4.4 分页

- 客户端分页（当前）：`PAGE_SIZE=10`
- 显示：`第 n / m 页，本页 x 条`
- 切换文件夹 / Tab / 搜索时重置到第 1 页

### 4.5 空状态文案

| 场景 | 标题 | 引导 |
|------|------|------|
| 团队无用例 | 暂无用例 | 导入用例 / 前往录制 |
| 文件夹为空 | 该文件夹暂无用例 | 移动用例进来 / 导入 |
| 搜索无结果 | 未找到匹配的用例 | 调整关键词或切换文件夹 |
