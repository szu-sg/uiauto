> **定位**：用例库（`CaseRepository`）是平台**控制面核心页面**，承接生产面 ① 录制、② 导入的入库结果，并为 ③ 计划选例、试跑提供入口。本文是 Epic H 的**页面级总设计**，子需求见 H01~H05。

---

## 1. 设计目标

| 目标 | 说明 |
|------|------|
| **统一模型** | 录制 / 导入 / MCP 用例在同一列表、同一编辑页、同一执行链，仅 `source` 标签区分来源 |
| **团队隔离** | 列表、文件夹、操作均限定 `req.teamId`（D1） |
| **可组织** | 文件夹树分组；未来可扩展标签检索，但不与文件夹重复造概念 |
| **可运维** | 批量移动、复制、删除、绑定计划；单条试跑/编辑路径清晰 |
| **去 Git** | 不展示 `repo_owner`、不拉外部仓库；路径仅为 workspace 标识 |

## 2. 信息架构

```
用例库 (/cases)
├── 左侧：目录树（REQ-H05）
│   ├── 全部用例（虚拟节点）
│   ├── 未分类（folder_id IS NULL）
│   └── 用户文件夹（多级）
├── 右侧：用例列表（REQ-H01）
│   ├── 顶栏：来源 Tab | 搜索 | 主操作（导入、前往录制、试跑历史）
│   ├── 表格：用例行 + 批量勾选
│   └── 底栏：批量操作（移动、复制、绑定计划、删除）
└── 弹层
    ├── 导入用例 ImportCaseModal（REQ-E03/E04）
    ├── 文件夹 新建/重命名/删除（REQ-H05）
    └── 移动到文件夹 MoveCaseModal（REQ-H05）

用例编辑 (/cases/:id/edit)（REQ-H02 + REQ-L03）
└── 与录制工作台同构：元信息 + 步骤 + 脚本 + 试跑

计划选例 (/plans/:id/cases)（REQ-I01）
└── 复用用例库数据；P2 增加文件夹筛选
```

## 4. 表格列规范（REQ-H01）

### 4.1 默认展示列

| 列 | 字段 | 说明 |
|----|------|------|
| 勾选 | — | 支持当前页全选；跨页批量（P2） |
| 名称 | `cases.name` | 主标识，可点击进入编辑 |
| 来源 | `cases.source` | 录制 / 导入；色块标签 |
| 文件夹 | `folder_id` → 名称 | 未分类显示灰色「未分类」 |
| 优先级 | `priority` | P0/P1/P2 |
| 标签 | `tags_json` | 最多展示 4 个 |
| 更新人 | `created_by` | 创建人 Chip |
| 更新时间 | `updated_at` | 相对时间 + tooltip 绝对时间 |
| 操作 | — | **主按钮「编辑」** + 「更多 ▾」（复制、删除、试跑 P2） |

### 4.2 默认隐藏（详情抽屉 / 悬停，P2）

- 备注 `description`
- 工作区路径 `team_id/case_id/case.spec.ts`
- 类型 `portability`（通用 / 绑定包）
- 创建时间 `created_at`

### 4.3 废弃列

- ~~仓库~~（`repo_owner/repo_name`）
- ~~模块~~（`metadata.module` 下拉）→ 由 **文件夹** 替代，见 §6

## 5. 筛选与搜索

| 维度 | 控件 | 数据 |
|------|------|------|
| 文件夹 | 左树选中 | `GET /api/cases?folder_id=` / `uncategorized` |
| 来源 | Tab | `source=recorded|imported`；「全部」不传 |
| 关键词 | 搜索框 | 名称、标签、描述、创建人；**有关键词时忽略文件夹**（全局搜） |
| 类型（P2） | 筛选器 | `portability=portable|bundle` |

团队切换（REQ-B05）后：刷新目录树 + 列表，选中文件夹重置为「全部」。

## 6. 概念统一：`module` vs `folder`

| 项 | 决策 |
|----|------|
| **分组唯一维度** | `cases.folder_id` → `case_folders` |
| **`metadata.module`** | **废弃写入**；录制/编辑页移除「模块」下拉（Phase B） |
| **历史数据** | 一次性迁移：`module` 非空 → 顶层文件夹；乱码/空名 → 「未分类」或合并到「其他」 |
| **展示** | 列表只显示文件夹列，不再显示 module |
