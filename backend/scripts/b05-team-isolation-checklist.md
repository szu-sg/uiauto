# B05 团队资源隔离 — 手工验收清单

在**两个不同协作空间**各准备一条用例/计划，用户 A 仅属于空间 1。

| # | 操作 | 期望 |
|---|------|------|
| 1 | A 的 JWT 在空间 1，`GET /api/cases/:id`（空间 2 的 id） | 404 |
| 2 | A `PATCH /api/plans/:id`（空间 2 的计划） | 404 |
| 3 | 切换空间后列表仅显示当前 `team_id` 数据 | 是 |
| 4 | 创建用例响应中 `team_id` = 当前 JWT 空间 | 是 |
| 5 | 计划保存 `case_ids` 含外空间用例 id | 400（若已实现校验） |

自动化冒烟：`node scripts/teamRoles-smoke.mjs`（角色矩阵，非跨团队）。
